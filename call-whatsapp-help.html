STEP 5

Frequently Asked Questions

Is the automated call free?

The call itself is charged at your mobile carrier's normal calling rate, same as any regular call. WhatsApp only needs an internet connection, so it's free to use over Wi-Fi or mobile data.

What if the WhatsApp bot doesn't understand my message?

Send just the keyword on its own — e.g. CODE — rather than a full sentence. If you're not sure what to send, type HELP and the bot will list all available keywords again.

Can I still reach an actual teacher?

Yes — press 0 on the automated call, or send TALK on WhatsApp. Both route you to a real person during 7 PM – 11 PM support hours; outside that window your request is queued for the next session.

Are these features live right now?

They're being rolled out — this page documents the planned menu and keyword flow. Until the automated helpline number is announced, use the direct WhatsApp number or email below for the same help.

Does this replace the Student Guide?

No — the Student Guide is still the full written reference. This page is a faster, phone-first way to reach the same information when you're on the move.
